# **电商下单 + 优惠券 测试用例集**

面向电商下单与优惠券场景的测试用例设计项目。共设计 69 条测试用例，覆盖 9 个功能模块，用例通过 Python 脚本结构化生成并导出为 Excel，便于维护与统计。

## **覆盖范围**

被测场景

- 商品加入购物车，购买数量 1–99

- 优惠券类型：满 100 减 20、满 200 减 50、新人券（无门槛减 10）

- 满减券不可叠加；新人券可与满减券叠加一次

- 优惠后金额不低于 0

- 支付方式：微信 / 支付宝 / 余额

- 余额不足时支付失败


设计维度

- **需求澄清**：针对模糊需求整理提问清单
- **判定表**：优惠券叠加与互斥规则
- **场景法**：下单主流程 + 备选流
- **等价类 + 边界值**：购买数量、金额
- **跳转用例**：商品页 → 购物车 → 结算页 → 支付页，覆盖带参与返回后状态
- **优先级**：P0–P3 分层


模块分布（9 个，共 69 条）

- 订单流程

- 购物车-加购

- 购物车-数量

- 优惠券

- 支付

- 金额计算

- 页面跳转

- 网络与环境

- 兼容性与界面



## **运行方式**

依赖：

pip install openpyxl
运行：

python _build_cases.py
说明：

- 脚本无命令行参数，会在当前目录生成 练习册E_电商下单+优惠券_测试用例.xlsx，同名文件会被覆盖

- 需先进入脚本所在目录再运行（脚本使用相对路径）

- 运行成功会打印 saved: ... cases: 69

- 用例数据集中在脚本顶部的 CASES 列表，格式为 (编号, 模块, 标题, 优先级, 前置条件, 步骤, 测试数据, 预期结果)，新增用例直接追加元组

- 统计页的 COUNTIF 范围由 len(CASES) 自动计算，增删用例后无需手动调整公式

## **文件说明**

- _build_cases.py：用例数据与 Excel 生成逻辑

- 练习册E_电商下单+优惠券_测试用例.xlsx：生成的用例表（用例明细 + 统计页）

- .gitignore：排除日志与缓存文件
